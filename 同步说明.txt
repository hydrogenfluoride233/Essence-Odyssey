本源远征 dev 版 —— 怎么同步、怎么启动
==========================================

第一次（只做一次）
  1. 装 GitHub Desktop，登录 GitHub，把公开库 clone 到电脑上
     建议直接 clone 进你的游戏实例目录（例：D:\EO-Dev）
  2. 双击本文件夹里的 sync-and-play.bat
     · 第一次要下约 795 MB 的模组（从 CurseForge 下，会有进度窗口）
     · 看到 [ok] Sync finished 就是好了

以后每次
  双击 sync-and-play.bat → 等它说好了 → 用你自己的启动器启动游戏
  （PCL / Prism / HMCL 都行，脚本不挑启动器）

要改点东西（发 PR）
  在这个文件夹里改 kubejs / config → GitHub Desktop 里 commit → 推到你 fork 的分支 → 发 PR

两种特殊情况
  · 提示 Java not found：把你的 java.exe 拖到这个 bat 上松手一次，路径会记住
  · 你的游戏目录不在这个文件夹：把游戏目录的路径写进 game-path.txt（一行），
    或者用命令行传第二个参数

脚本都做了什么
  ① 拉最新的模组清单（git fetch upstream + merge）
  ② 照清单把模组/配置同步进游戏目录（packwiz-installer；模组从 CurseForge 下载）
  它不会覆盖你自己改过的文件 —— 那些会提示 Hash invalid 并保留你那份
